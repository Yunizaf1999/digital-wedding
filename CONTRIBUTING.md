# Contributing to Digital Wedding Template

Kami sangat senang jika Anda ingin berkontribusi pada proyek ini! 🎊

## Cara Berkontribusi

### 1. Fork Repository
Klik tombol "Fork" di GitHub

### 2. Clone Repository
```bash
git clone https://github.com/yourusername/digital-wedding.git
cd digital-wedding
```

### 3. Buat Branch Baru
```bash
git checkout -b feature/nama-fitur
```

### 4. Buat Perubahan
Lakukan perubahan yang Anda inginkan pada kode

### 5. Commit Changes
```bash
git add .
git commit -m "Add: Deskripsi perubahan yang jelas"
```

### 6. Push ke GitHub
```bash
git push origin feature/nama-fitur
```

### 7. Buat Pull Request
Di GitHub, buat Pull Request dari branch Anda ke main branch

## Konvensi Commit

Gunakan format berikut untuk commit messages:

- `feat:` untuk fitur baru
- `fix:` untuk bug fixes
- `docs:` untuk dokumentasi
- `style:` untuk formatting
- `refactor:` untuk refactoring kode
- `test:` untuk testing
- `perf:` untuk performance improvements

Contoh:
```
feat: Add dark mode toggle
fix: Fix countdown timer bug
docs: Update installation guide
```

## Pedoman Kode

### JavaScript/React
- Gunakan ES6+ syntax
- Indent dengan 2 spaces
- Gunakan meaningful variable names
- Tambahkan comments untuk logika kompleks

### CSS
- Gunakan Tailwind CSS classes
- Ikuti color naming convention
- Mobile-first approach

### Dokumentasi
- Update README jika ada fitur baru
- Tambahkan komentar untuk fungsi kompleks
- Jelaskan perubahan di commit message

## Jenis Kontribusi yang Diterima

✅ **Bug Fixes** - Perbaikan bugs yang ada

✅ **New Features** - Fitur-fitur baru yang berguna

✅ **Documentation** - Perbaikan dokumentasi

✅ **Performance** - Optimasi performa

✅ **Code Quality** - Refactoring & cleanup

✅ **Translations** - Terjemahan ke bahasa lain

## Tidak Diterima

❌ Perubahan kecil tanpa value

❌ Menghapus fitur tanpa diskusi

❌ Code dengan style tidak konsisten

❌ Perubahan besar tanpa issue discussion

## Proses Review

1. Setiap PR akan di-review oleh maintainer
2. Mungkin ada request untuk changes
3. Setelah approval, PR akan di-merge
4. Terima kasih atas kontribusi Anda! 🙏

## Questions?

- Buka GitHub Issues untuk pertanyaan
- Diskusi di GitHub Discussions
- Email: contact@digitalwedding.com
