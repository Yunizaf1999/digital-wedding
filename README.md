# Digital Wedding Template 💒

Template pernikahan digital modern dan elegant dengan animasi yang memukau dan fitur-fitur canggih.

## 🌟 Fitur Utama

- **Galeri Foto Animatif** - Animasi SVG yang elegan tanpa menampilkan wajah nyata
- **Countdown Timer** - Penghitung mundur menuju hari istimewa
- **Background Music** - Musik latar yang indah dan menenangkan
- **Timeline Acara** - Jadwal lengkap acara pernikahan dengan animasi
- **Buku Tamu Digital** - Koleksi ucapan dari tamu-tamu
- **Animasi Scroll** - Efek smooth scroll yang profesional
- **Efek Partikel & Kembang Api** - Perayaan visual yang spektakuler
- **Dark Mode/Light Mode** - Tema yang dapat disesuaikan
- **Responsive Design** - Sempurna di semua perangkat
- **PWA Ready** - Bisa diakses offline

## 🛠 Teknologi yang Digunakan

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla + ES6+)
- **Framework**: React 18, Vue 3
- **Animasi**: Framer Motion, GSAP, Three.js
- **UI Library**: Tailwind CSS, Bootstrap 5
- **Partikel**: Tsparticles, PixiJS
- **Database**: Firebase (untuk Buku Tamu)
- **Build Tool**: Vite, Webpack
- **PWA**: Service Workers

## 🚀 Instalasi & Menjalankan

### Dengan React/Vue
```bash
# Install dependencies
npm install

# Development server
npm run dev

# Build untuk production
npm run build
```

### Versi Vanilla
Buka `vanilla/index.html` langsung di browser.

## 📖 Dokumentasi

Setiap komponen memiliki dokumentasi lengkap di folder masing-masing.

## 💝 Kustomisasi

Edit file `config.js` untuk mengubah:
- Tanggal pernikahan
- Nama pasangan
- Warna tema
- Musik background
- Timeline acara
- Pesan ucapan
